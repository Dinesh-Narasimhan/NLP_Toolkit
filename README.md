# 🧠 NLP Toolkit — All-in-One Text Intelligence App

NLP Toolkit is a simple, powerful web app built using **Streamlit** and **Transformers** that allows users to:
- 🔁 Translate text
- ✂️ Summarize content
- 😊 Analyze sentiment
- 🏷️ Classify topics

All modules are powered by pre-trained Hugging Face models and run on both local machines and **Streamlit Cloud**.

---

## 🚀 Features

| Feature          | Description                                                          |
|------------------|----------------------------------------------------------------------|
| Translation      | Translation between  Hindi, Tamil, Telugu, Malayalam, Japanese, etc. |
| Summarization    | Summarize long English texts using a Transformer model               |
| Sentiment        | Detect sentiment (positive/negative)                                 |
| Classification   | Classify text into general categories                                |
